# TudásTér AI

**TudásTér AI** is a premium, multilingual, AI-powered deep-research and visual-infographic web application. It synthesizes scientifically grounded, high-credibility research reports separating peer-reviewed evidence from social media hype, featuring interactive credibility meters, comparative visualizations, curated source libraries, and actionable roadmaps.

## Architecture & Deployment Workflow

- **Local Development**: Clean vanilla / modern web application architecture.
- **Source Control**: Continuous integration via GitHub (`BartalBoti/tudastarai`).
- **Production Deployment**: Automated CI/CD pipeline via Vercel. Pushes to `main` automatically build and deploy to the live production environment.
